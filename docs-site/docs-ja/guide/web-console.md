# Web コンソールと MCP

`win-sshpass -web` はブラウザー内にローカル SSH ワークスペースを起動します。
`-h` または `-f` で SSH ホストを指定する必要があります。SFTP 管理、実ターミナル、
MCP ツールを提供します。

## 起動

接続情報付きで自動ログイン：

```bash
win-sshpass -web -h 127.0.0.1 -u root -P 22 -p 'password'
```

<http://127.0.0.1:6326> を開くと自動接続してワークスペースを表示します。

`win-sshpass -web` だけではエラー終了します。設定ファイルを使用する場合：

```bash
win-sshpass -f server.config -web
```

待受アドレスの変更：

```bash
win-sshpass -web -h example.com -u root -p 'password' -web-addr 127.0.0.1:6326
```

既定ではループバックのみです。別インターフェースにバインドすると、その
ネットワークへ Web ワークスペースを公開します。

## ワークスペース

### SFTP ファイルマネージャー

- リモートパスの入力、親ディレクトリへの移動
- ダブルクリックでディレクトリを開く
- アップロード/ダウンロード
- ディレクトリ作成
- ファイルまたは空ディレクトリの削除
- ローカルのファイル/フォルダーを左側へドラッグ＆ドロップ
- リモートファイルをブラウザー外へドラッグしてダウンロード
- 下部にファイル名、順序、バー、全体パーセントを表示

フォルダーをドロップするとリモートディレクトリを再帰作成します。

### SSH ターミナル

- 継続的な対話入力と ANSI 出力
- Shell 履歴、Tab 補完、全画面アプリ
- ターミナルサイズの自動同期
- クリアと再接続

xterm.js とリモート Shell の間を WebSocket でバイト転送する実際の PTY です。

### 可変レイアウト

中央の分割バーをドラッグして幅を変更します。フォーカス後に左右方向キーでも
調整でき、幅はブラウザーに保存されます。

### テーマ

- **System** — `prefers-color-scheme` に従う既定設定
- **Light**
- **Dark**

xterm の配色も連動します。

## セキュリティ

ブラウザーにはランダムな `HttpOnly`、`SameSite=Strict` Cookie を発行します。
Cookie にパスワード、ユーザー名、ホストは含まれません。SSH Client と認証情報は
ローカルサーバープロセスだけに保持され、30 分間操作がないと期限切れになります。

HTTP API は JSON を要求し、クロスオリジン操作を拒否します。

## MCP

Web サーバーは既定で Streamable HTTP MCP を公開します：

```text
http://127.0.0.1:6326/mcp
```

MCP は `-web` 起動時の SSH 接続情報を使用します。

### Codex 設定

```toml
[mcp_servers.win-sshpass]
url = "http://127.0.0.1:6326/mcp"
```

初期化応答の `Mcp-Session-Id` を後続リクエストへ指定します。`DELETE /mcp` で
セッションを終了できます。

### ツール

| ツール | 用途 |
|---|---|
| `ssh_exec` | SSH コマンドを実行し stdout、stderr、終了コードを返す |
| `sftp_list` | リモートディレクトリを一覧表示 |
| `sftp_read` | UTF-8 テキストファイルを読む |
| `sftp_write` | テキストまたは base64 で作成/上書き |
| `sftp_mkdir` | 親を含めてディレクトリを作成 |
| `sftp_delete` | ファイルまたは空ディレクトリを削除 |

## リバースプロキシ

TLS をプロキシで終端する場合、`/api/terminal` の WebSocket Upgrade と
`Mcp-Session-Id` ヘッダーを転送してください。リモート公開が不要なら、既定の
ループバックバインドを維持してください。

## トラブルシューティング

- **Connecting のまま** — 通常 CLI でホスト、ポート、パスワード、鍵、プロキシを確認。
- **ターミナルが切れる** — 再接続し、サーバーログの SSH/プロキシエラーを確認。
- **ファイル操作に失敗** — SSH アカウントの権限と SFTP の有効化を確認。
- **MCP tools/list に失敗** — initialize を完了し `Mcp-Session-Id` を保持。
